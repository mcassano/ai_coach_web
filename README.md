# AI Coach Web system

# Installation
```
git clone ...
python3 -m venv my_venv
source my_venv/bin/activate
pip3 install -r requirements.txt
```

# Set up config

```
export SECRET_KEY=whatevs
```

# Start the web
```
./manage.py migrate
./manage.py runserver
```


# Run tests

```
./manage test
```
